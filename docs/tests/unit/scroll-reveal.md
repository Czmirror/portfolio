# Unit test spec: スクロール時の表示判定

- 対象: `public/assets/js/animations.js` の `checkSlideIn` とイベント登録。
- 承認範囲: 会話で依頼された「ページ途中でリロードするとコンテンツが消える」不具合の修正。
- 原因: `offsetTop` は親要素基準で、画面全体の `scrollY` と比較すると入れ子要素の位置を誤判定する。
- 方針: `getBoundingClientRect().top` で画面座標を使う。復元位置より上の要素も表示済みにし、load / pageshow / resize / scrollで再判定する。画像URLとレイアウトは変えない。

| ケースID | 観点 | 条件と期待結果 | 対応するtest名 | 結果 |
| --- | --- | --- | --- | --- |
| UT1 | 入れ子・画面境界 | 親基準の座標に依存せず、画面内と通過済みは表示、画面下端以降は待機 | 途中リロードで画面内・通過済みの入れ子要素を表示する | 成功 |
| UT2 | スクロール復元 | 初期判定後の位置変更を各イベントで反映。一度表示した要素は隠さない | load / pageshow / resize / scrollでスクロール復元後の位置を再判定する | 成功（4件） |
| UT3 | アクセシビリティ | 動きを減らす設定では全要素を表示 | 動きを減らす設定では画面外の要素も表示する | 成功 |

- 実行: `node --test tests/animations.test.cjs`。実装本体をVMで読み込み、DOMとイベントだけを置き換える。
- `node --check public/assets/js/animations.js`、公開用ビルド、差分の空白検査も成功。
- ブラウザで自己紹介の途中リロードを再現し、修正後はプロフィールと各列が表示済みになることを確認。
