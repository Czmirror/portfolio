# ポートフォリオのアクセス計測

目的は本番の訪問と、作品・相談導線への関心を評価すること。

- AC1: GAタグはHTTPSの `czmirror.github.io` の `/portfolio/` 配下でのみ読み込む。ローカル・file・別サイトでは初期化も追加イベント送信もしない。
- AC2: Web作品とゲームの外部リンクで `work_link_click` を送り、固定の `item_id` と `link_type` で作品と行き先の種類を判別できる。
- AC3: `#contact` へのリンクで `contact_click`、`#consultation` へのリンクで `consultation_click` を送り、固定の `placement` でナビ・ヒーロー等を判別できる。
- AC4: 計測失敗時も通常のリンク操作を維持する。Reactによる後からの描画、リンク内の子要素、キーボードによるリンク起動も対象にする。
- AC5: 追加イベントには自由文・メール・問い合わせ内容・リンクの生URLを送らない。未知の作品IDや未対応の行き先は追加計測しない。既存GAの標準収集とは区別する。

測定IDは既存の `G-JS9MLQN89W` を維持する。Googleフォーム内の送信はクロスオリジンのため今回の対象外。クリックを問い合わせ完了や作品起動成功として扱わない。キーイベント登録・管理画面の設定変更は行わない。

実装・検証は `docs/work/portfolio-analytics/plan.md` と各試験記録を参照。最終更新: 2026-10-27。
