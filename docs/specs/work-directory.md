# 作品ガイド

制作実績の入口から作品・楽曲・共同制作の紹介を探せる、ページ内の目次です。

- AC1: 制作実績の冒頭に「作品ガイド」を表示し、Webツール3件・ゲーム7件・BGM2曲・コラボレーション1件へ名前で移動できる。
- AC2: リンク先で該当作品や楽曲の紹介を読める。既存の`rayser`・`chikenrunv2`アンカーは維持し、他のゲームにも一意のアンカーを付ける。
- AC3: キーボードで選択・移動でき、固定ナビゲーションが移動先を隠さない。390px幅でも欠けや横はみ出しがない。
- AC4: 既存の詳しい紹介、掲載順、画像・動画パスを維持する。ガイドの操作でコンテンツを非表示にしない。

リンクは同一ページ内の固定IDだけを使います。検索入力・絞り込み状態・保存・新しい外部通信は追加しません。作品名は既存データを再利用し、BGMは試聴データを持つ2曲を案内します。
