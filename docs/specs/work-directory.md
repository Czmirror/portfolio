# 制作実績のカテゴリ案内

制作実績の冒頭に「Webツール｜ゲーム」の2リンクをタブ風に表示します。内容は切り替えず、各カテゴリの紹介見出しへ通常のアンカーリンクで移動します。

- AC1: 案内はWebツール・ゲームの2つだけ。作品名一覧、BGM・コラボレーションの案内は表示しない。
- AC2: 各リンクからWeb制作物・ツール、ゲーム制作実績の見出しへ移動でき、固定ナビゲーションに隠れない。
- AC3: 390px幅でも2つを横並びで読め、キーボードfocusとEnterで操作できる。
- AC4: BGM・コラボレーションを含む既存の紹介本文・掲載順・画像と動画パスは維持する。

`role="tab"`や選択状態は付けません。見た目はタブ風ですが、操作はページ内リンクです。既存の作品別アンカーは互換性のため維持します。
