# ゲーム用BGMの紹介

個人制作のゲームと音楽制作経験を結び付けて紹介する。

- Captulionには「Captulion stage1 mission」、TurboSobaには「Turbo Soba! Stage」を掲載する。曲は本人が選んだ自作BGMとして説明する。
- 自動再生なしのSoundCloudプレイヤーと、再生できない環境向けの直接リンクを各作品紹介に置く。音源そのものは保存・加工・再配布しない。
- TypeGunnerはSunoを活用したゲーム用楽曲制作・組み込み経験として記す。手作業の作曲・編曲や音源ライセンスは断定しない。
- RAYSERはSteam公開版で外部提供楽曲を使用していることを記す。過去の自作曲を現行版の使用曲として紹介しない。
- 既存の作品リンク、画像・動画のパスと全体レイアウトを保つ。

掲載データは `src/data/portfolioData.json`、表示は `GameSection.jsx`、受け渡しは `Portfolio.jsx` が担当する。
受け入れ条件AC1〜AC4と検証結果は [作業記録](../work/game-music-showcase/plan.md) に記載。新しい計算や状態管理はなく、形式だけの単体試験は追加しない。
