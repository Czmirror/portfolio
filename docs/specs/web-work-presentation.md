# Web制作実績の見せ方

Product Designで選択された1案目に合わせ、画像と短い説明で作品を見渡せる紹介にします。

- AC1: 制作実績の見出しと2カテゴリのページ内リンクを維持し、Web制作物3件を画像左・説明右の順で並べる。スマホは画像、説明の順に1列。
- AC2: 一覧に作品名・概要・作品を開くリンクを表示し、既存の詳しい説明は「制作の詳細」から展開できる。内容と関連リンクは削除しない。
- AC3: 紺・シアンの既存配色、実際のスクリーンショット、薄い背景素材を使い、二重のカード枠を除く。
- AC4: 画像・動画の相対パス、掲載順、ゲーム・BGM・共同制作・相談欄、GAの分類を維持する。新しい外部通信・依存は増やさない。
- AC6: 自己紹介に経歴由来の3つの強みを図解画像で示す。代替テキストと説明文・原寸画像への拡大リンクを用意する。
- AC5: PC・390px幅で欠けや横はみ出しがなく、リンクと詳細開閉をキーボードで操作できる。参照画像と実装を並べて比較する。

見本のナビゲーションの配置・生成画像内の小さな文字は、そのままサイトへ転写しません。既存のサイト全体のナビゲーションは維持し、実際の作品説明を正本とします。制作の詳細はブラウザ標準のdetails/summaryを使い、閉じた状態から開始します。
