# 1案目を制作実績へ取り入れる

## 進め方

今のWeb作品紹介は枠と長い説明が重なっています。選択された画像のように、作品の画面・短い紹介・開くボタンが先に目に入る構成へ整えます。

1. 既存の3作品の画像・本文・リンクを保ったまま、左右の紹介へ組み替えます。
2. 詳しい説明は「制作の詳細」にまとめ、必要なときに開けるようにします。
3. 1案目の画像と実画面を並べ、文字・余白・配色・画像・内容を照合します。
4. PCとスマホ、カテゴリ移動、詳細開閉、作品リンクを確認してコミットします。

承認の出典は会話の「それでは1の方向で」です。表示順で最初の生成画像`exec-e651ce4c-2520-4411-84eb-7ad6a41f4199.png`を使います。今回の既存リポジトリ改善では、新しいプロトタイプの雛形は作りません。従来の通常PR・レビュー方針を維持し、公開前にローカルで検証します。

## ファイルの役割

`Portfolio.jsx`は既存の静的掲載データと表示の組立を持ちます。今回も文言・URLの正本を増やさず、Web作品の一覧と詳細を同じデータから表示します。`styles.css`はWeb紹介専用の範囲で文字・余白・2列配置を調整します。旧カード・グリッドCSSは置き換え、未使用の装飾を残しません。

詳細開閉はブラウザが持ち、Reactに新しい状態やイベントを増やしません。固定HTTPSの既存リンクとReactのテキスト描画を維持します。作品を開くリンクは既存の`data-analytics-work`内に置き、送信する分類は変えません。DB・権限・外部送信先・依存・CI・ハーネスの変更はありません。

見本の画面は1488×1056px。画像の自然な16:9比率、画像約62%・説明残り、見出し52px、作品名52px、本文18px、作品間隔28pxを初期値にします。これらは見本から推定した仮の調整値としてCSS変数にまとめ、ブラウザ比較で調整します。日本語の実際の文量を優先します。
