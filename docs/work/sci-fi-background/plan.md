# 自己紹介にSF風の背景を試す計画

## 目的と範囲

- 自己紹介セクションだけに静かなSF風背景を1枚配置し、既存のダークテーマに奥行きを加える。
- 見た目の水準は既定のB（共有・デモ用）。最初は局所的に試し、人間確認後にほかのセクションへの展開を判断する。
- HTMLの構造、掲載文、段組み、余白、文字・画像サイズ、既存の画像URL、ゲーム本体は変更しない。
- 承認出典: 本計画へのユーザーの「ok」。生成・実装までを対象とし、push・PR・本番公開は含まない。

## 背景の制作

1. Canvaの画像生成で横長16:9の背景を1枚作る。
2. モチーフは細い回路線、疎らなグリッド、小さな粒子。暗い紺にシアンとごく薄い青紫を使う。
3. 文字、数字、ロゴ、人物、宇宙船などの主役は入れない。中央は暗く静かに保ち、線や光を端に寄せる。
4. Canvaへ送る情報は上記の汎用的な画像指示だけ。氏名、経歴、ソース、添付画像は送らない。
5. 有料の購入や素材契約は行わない。生成クレジット不足や利用条件の問題があれば報告する。
6. 生成元、素材ID、作成日、利用条件と必要なクレジットを素材台帳に残す。Web公開と公開リポジトリへの格納可否を確認できるまで取り込まない。

## 実装

- 背景素材は `public/assets/image/backgrounds/` に新しいファイルとして保存する。既存画像を上書きしない。
- 当初はWebP・長辺1600px程度・200KB以下を目安としたが、取得したPNGは生成来歴情報を含むため変換しない。ユーザーの「原本で試す」の承認に基づき、1680×944px・1,469,217 bytesの原本を利用する。画素・来歴情報は変更しない。
- `public/assets/css/styles.css` の `#about` だけにCSS背景として適用する。背景レイヤーは本文の不透明度やクリック判定に影響させない。
- 暗色のグラデーションを重ね、上下の境界を自然になじませる。画像そのものは描き直さない。
- 見え方の強さはCSS変数1か所で調整する。初期値は画像の見え方10%程度を仮とし、スマホではさらに控えめにする。
- 背景は静止画。追加のJavaScript、アニメーション、外部配信、フォント・ライブラリの導入は行わない。
- 通信失敗時も既存の背景色で読める状態を保つ。

- 新規の業務ロジックはなく、意味のない単体テストは追加しない。既存の回帰テストと実画面検証を使う。
- 成果物は背景画像・素材台帳・CSS差分。確認結果と採用した仮の値はこの計画へ追記する。
- 変更のまとまりごとに通常コミットし、ユーザーの既存変更は含めない。
- 元に戻す場合は新たな `#about` の背景指定だけを外す。既存の配色・本文・画像はそのまま残る。
