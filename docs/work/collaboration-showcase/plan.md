# コラボレーション紹介とカードの見せ方を整える

## 今回やること

「犯罪者隔離世界」への参加経験を、担当した部分がすぐ分かる形で追加します。すでに作ったゲームBGM紹介も含め、音づくりと共同制作の経験が伝わる通常PRにまとめます。

1. 作品名、担当範囲、公式リンクを確認します。
2. 個人制作とは別に「コラボレーション」を追加します。
3. Canvaで見せ方を検討し、既存のカードへ余白・細い枠・文字の強弱を取り入れます。
4. PC・スマホで表示、リンク、BGM再生を確かめます。
5. 独立したAIレビューとチェックを経て通常PRを作り、問題がなければマージします。

## 守ること

- [仕様](../../specs/collaboration.md)のAC1〜3を[機能試験](../../tests/functional/collaboration.md)で確認します。BGMの仕様と検証記録は既存の`game-music-showcase`にまとめたままにします。
- 2026-10-31の会話「追加お願いします。名前はコラボレーション」「通常PRを作成して、レビューとチェックに問題がなければマージまで」が今回の実装・push・PR・条件付きmergeの承認です。掲載許可は直前の本人の説明を根拠とします。
- `codex/game-music-showcase`の42fd8b2から継続。fetch後の`origin/main`はe99ac3cで、BGM関連の2commitだけが先行しています。未コミットの`game/`と`game.html`は保護し、PRに含めません。
- 公式サイトは通常の取得が失敗したため、公開URLをJina経由で確認しました。ジャンルはミニゲームを含むADV。公開予定など古い情報は転載しません。
- UI visualの既定のBを採用します。既存のレイアウト、見出し、作品画像と動画の相対パスを保ちます。Canvaは外観の参考用とし、新しい画像素材は公開しません。

## 変更する場所と確認方法

| 対象 | 役割と今回の変更 | 確認 |
| --- | --- | --- |
| `Portfolio.jsx` | 既存の作品紹介の組立に、静的なコラボレーション紹介を追加 | AC1・2、公式URL、見出しの順序 |
| `GameSection.jsx` | 各ゲームのBGM説明を同じカード内でまとめる | 既存の音楽文言・URLを保ち、2曲を再生 |
| `styles.css` | 既存配色で紹介枠を整える | AC3、幅390pxと1280px、focusと横はみ出し |
| `README.md` | 掲載情報の編集場所を案内 | 実際のファイルとの一致 |

既存の`store-card`・`case-format`を再利用します。コラボレーションは1件の静的紹介なので、別のデータ形式や汎用コンポーネントは増やしません。既存の表示責務内の変更であり、状態・保存・外部通信処理は追加しません。

入力はレビュー対象の固定JSXのみ。Reactの通常のテキスト出力を使い、外部リンクは固定HTTPS URLと`noopener noreferrer`を指定します。公式サイトへの遷移は利用者のクリック時だけです。BGM埋め込みの通信先・再生条件は変更しません。認証・個人情報・DB・依存・CI・ハーネスは対象外です。

余白は既存の段階に合わせ、紹介枠の内側余白`--showcase-padding: 1.5rem`、ラベル文字間`--showcase-label-spacing: 0.08em`を仮の値としてCSSでまとめます。色と角丸は既存値を使います。新たな演出や背景画像は増やしません。

検証は既存のアニメーション・解析イベントの12test、Pages用build、`git diff --check`、ブラウザ確認、最終差分レビューを行います。重要な新規ロジックはないため単体試験は追加しません。lint・型検査は既存コマンド未設定。既知のVite警告と遅延読み込みの問題は`docs/known-issues.md`を参照し、今回の変更に混ぜません。

問題が出た場合は今回のcommitだけを戻す修正PRで対処します。ユーザーのゲーム試作には触れません。
