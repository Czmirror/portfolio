Web開発経験

  • PHP / Laravelを中心に、会員基盤・認証・権限管理、管理画面、バッチの設計・実装と、サービスの長期運用・改善を経験しています。
  • KeycloakによるSSO（シングルサインオン）連携、MariaDB / Mroongaによる全文検索改善、OracleからPostgreSQLへの移行を伴うPHP改修の経験があります。
  • Amazon Linuxの移行では、AMI作成、Ansible / Packerを使った環境構築、ミドルウェア差分の確認、CloudWatch Logsによるログ保全の試験・運用手順整備に携わりました。
  • CMS案件、Ajax対応、テンプレート設計などの実績があり、要件定義、DB設計、実装、検証、運用までの経験があります。スクラム体制での開発も経験しています。
  • 個人開発ではTypeScript / React / Next.js、Node.js、Prisma、PostgreSQLを使用。Codex / Claude Codeを活用し、AIの生成結果をレビューしながら実装しています。

ゲーム開発経験

  • Unity、C#、Godot Engineを用いた個人ゲーム開発経験があり、iOSアプリおよびSteam向けゲームのリリース実績があります。
  • UI、アニメーション、スクリプトの設計・実装に加え、一部の自作ゲームではBGM制作にも取り組んでいます。
  • Captulion・TurboSobaの自作BGMをSoundCloudで公開しています。TypeGunnerではSunoを活用して楽曲を制作しています。
